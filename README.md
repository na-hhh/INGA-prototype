# INGA — Étude architecturale interactive 01

Prototype 3D navigable en navigateur, réalisé avec Three.js et Vite. Ce prototype est une **étude spatiale**, pas encore un rendu photoréaliste ni une boutique prête à publier.

## Installation (pour débutant)

1. Installer Node.js (version LTS) depuis https://nodejs.org
2. Ouvrir le dossier `INGA-prototype` dans Cursor.
3. Dans Cursor, ouvrir **Terminal > New Terminal**.
4. Entrer `npm install` puis valider.
5. Entrer `npm run dev` puis valider.
6. Ouvrir l'adresse locale affichée (généralement `http://localhost:5173`).

## Commandes

- ZQSD ou WASD : se déplacer
- Souris : regarder autour (cliquer dans la scène si nécessaire)
- Espace : sauter / léviter
- E : ouvrir une fiche d'œuvre proche
- Échap : quitter le contrôle souris
- Mobile : joystick à gauche, glisser à droite pour regarder, flèche pour sauter
- Son : bouton facultatif en haut à droite

## Étapes suivantes

- Remplacer les matériaux procéduraux par des textures PBR détaillées et correctement licenciées.
- Créer des objets 3D sur mesure (textiles, mocassins, mobilier, sculptures).
- Travailler l'éclairage indirect et les ombres pour rapprocher le rendu de l'image d'intention.
- Remplacer les œuvres temporaires par les vraies œuvres et ajouter des fiches produits.
- Ajouter des sons de vent, de feuilles et d'eau enregistrés, mixés en boucle longue.
- Mettre en place le multijoueur et le système de vente dans des phases ultérieures.

Le prototype utilise des œuvres factices et un son synthétique. Aucun paiement ni présence multi-utilisateur n'est encore actif.
